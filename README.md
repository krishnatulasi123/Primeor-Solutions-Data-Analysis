# E-Commerce Data Analysis

## Project Overview

This project analyzes e-commerce sales data to identify business trends, sales performance, profitability, customer behavior, product performance, market performance, and shipping patterns.

The project uses **Excel, MySQL, and Power BI** to clean, analyze, visualize, and present the data-driven insights.

## Tools & Technologies

* **Excel** – Data cleaning, analysis, pivot tables, and charts
* **MySQL** – Data storage, SQL queries, and business analysis
* **Power BI** – Interactive dashboard and data visualization

## Project Workflow

1. Data cleaning and preparation using Excel
2. Basic sales and profit analysis
3. SQL data import and validation using MySQL
4. Business analysis using SQL queries
5. Interactive dashboard creation using Power BI
6. Final business insights and recommendations

## Key Business Insights

### Market Performance

**APAC** generates the highest market revenue, making it an important market for business growth.

### Category Profitability

**Office Supplies** is the least profitable category, with an average profit of **16.57**.

### Shipping Analysis

**Standard Class** is the most commonly used shipping mode, with **30,764 orders**.

### Product Performance

**Phones** is the highest-selling sub-category, generating approximately **1,706,642** in sales.

### Regional Performance

The **Central region** generates the highest regional sales, with approximately **2,821,740** in sales.

## Power BI Dashboard

The Power BI dashboard provides a visual overview of:

* Total Sales
* Total Profit
* Sales by Region
* Profit by Category
* Sales by Market
* Product Performance
* Shipping Mode
* Sales Trends

## Business Recommendations

* Focus on high-performing markets such as APAC.
* Improve profitability in the Office Supplies category.
* Review pricing and discount strategies.
* Investigate negative-profit orders.
* Maintain sufficient inventory for high-demand products.
* Optimize Standard Class shipping operations.
* Use historical sales trends for inventory and marketing planning.

## Conclusion

This project demonstrates how **Excel, SQL, and Power BI** can be combined to transform raw e-commerce data into meaningful business insights.

The analysis supports data-driven decision-making related to sales growth, profitability, customer behavior, product performance, market expansion, and logistics optimization.
