Project: E-Commerce Data Analysis

Tools:
Excel | MySQL | Power BI

Project Objective:
Analyze e-commerce sales data to identify sales trends, profitability, market performance, product performance, customer behavior, and shipping patterns.

Key Insights:

APAC generated the highest market revenue.
Office Supplies was the least profitable category, with an average profit of 16.57.
Standard Class was the most commonly used shipping mode, with 30,764 orders.
Phones was the highest-selling sub-category based on your SQL results, with sales of 1,706,642.

Deliverables:

Cleaned dataset
SQL analysis
Excel analysis
Power BI dashboard
Final business insights report
